## How to add these to your Xavvi dashboard

1. Go to https://shop.xavvi.com/admin (or wherever your creator dashboard is — adjust based on your invite)
2. Log in
3. Find the **Products** section
4. For each of the 14 products above:
   - **Title** = Title column
   - **Price** = Price column (in dollars)
   - **Description** = Description column (if available)
   - **Variants** = Add size (S/M/L/XL/XXL) and color swatches
   - **Images** = Upload the product photos (or reference the original thedtrbrand.com URLs)
   - **Collection** = Tag with the collection name (DTR LOGO, THE CHAIN, etc.)
5. Save
6. After all 14 are added, refresh http://localhost:5173 — products should appear in `/shop` and `/`

## Tips

- **Order matters for product order in your shop** — the list above is roughly the order they appear on thedtrbrand.com
- **Use the same title format** — "DTR LOGO Tee" not "DTR Logo Tee" (preserve exact casing from the original site)
- **Use the same handle** — e.g. `dtr-logo-tee` — this becomes the URL slug
- **If a product has more than one image** — add all of them, the storefront carousel will use them
- **If you want to skip a product** — that's fine, only the ones you add will appear
- **If a product is out of stock** — set inventory to 0 instead of deleting
